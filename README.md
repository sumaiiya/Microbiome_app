# Microbiome Simulation and Interactive Analysis Platform

This project was developed during my research internship at INRAE. It provides an interactive platform for simulating, analysing, and visualising microbial dynamics using database-initialised parameters and scientific simulation tools.

## Research Context

The project focuses on computational modelling of microbial systems, with an emphasis on simulation, data-driven parameter management, and interactive exploration of model behaviour.

## Main Features

- Data-driven simulation of microbial dynamics
- Backend API for model execution
- Interactive frontend interface
- Streamlit dashboard for scientific visualisation
- Reproducible structure for experimentation and analysis

Installation
1. Clone the repository
git clone https://github.com/sumaiiya/Microbiome_app.git
cd Microbiome_app
2. Install Python dependencies
pip install -r requirements.txt
3. Run the backend
cd backend
python app.py
4. Run the frontend
cd frontend
npm install
npm start
5. Run the Streamlit dashboard
cd StreamLitApp
streamlit run app.py
